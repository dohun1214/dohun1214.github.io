Note

한 사람이 PC·아이폰·웹에서 같이 쓰는 개인용 메모 앱입니다.

무엇을 하나요

  • 메모 쓰기·폴더 정리·검색, 서식 텍스트와 마크다운
  • 사진·파일 첨부, 날짜와 D-day 표시
  • 여러 기기 사이 자동 동기화 (본인이 운영하는 서버)
  • 구글 캘린더 연결: 내 일정을 앱 안에서 보고, 추가·수정·삭제하고, 일정을 골라 메모에 D-day 로 넣기

구글 계정 사용

구글 캘린더 연결은 사용자가 직접 켤 때만 동작합니다. 앱은 연결한 계정의 캘린더 목록과 일정만 다루며, 그 정보를 다른 곳에 보내거나 광고에 쓰지 않습니다. 자세한 내용은 개인정보처리방침을 봐 주세요.

Note is a personal note-taking app used by its developer only. Google Calendar access is used solely to show and edit the user's own events inside the app. See the Privacy Policy.
