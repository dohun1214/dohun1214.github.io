개인정보처리방침

시행일: 2026년 11월 9일

Note(이하 "앱")는 개발자 본인이 개인적으로 쓰는 메모 앱입니다. 이 방침은 앱이 구글 계정 정보를 어떻게 다루는지 설명합니다.

1. 다루는 정보

  • 구글 계정 이메일 주소 (어느 계정에 연결됐는지 보여 주기 위해)
  • 구글 캘린더의 캘린더 목록과 일정 (제목, 시간, 장소, 설명, 색)
  • 구글이 발급한 인증 토큰 (다시 로그인하지 않고 캘린더에 접근하기 위해)

2. 쓰는 목적

앱 안에서 사용자의 일정을 보여 주고, 사용자가 요청할 때 일정을 추가·수정·삭제하며, 메모에 일정 D-day 를 넣는 데에만 씁니다.

3. 보관

인증 토큰과 계정 이메일은 사용자 본인이 운영하는 앱 서버에만 저장됩니다. 일정은 빠르게 보여 주기 위해 사용자 기기에 임시로 저장될 수 있습니다. 일정 원본은 구글 캘린더에 그대로 있습니다.

4. 제공·공유

구글 사용자 데이터를 판매하거나, 광고에 쓰거나, 다른 사람·회사에 넘기지 않습니다. 앱의 구글 API 사용은 Google API Services User Data Policy의 Limited Use 요구 사항을 따릅니다.

5. 연결 끊기와 삭제

앱 설정의 "연결 끊기"를 누르면 토큰을 폐기하고 서버에서 지웁니다. 구글 계정 권한 페이지에서도 언제든 접근을 취소할 수 있습니다.
